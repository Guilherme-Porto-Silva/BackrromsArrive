# Projeto

## Ideia geral do jogo

* Low top down strucute.

* Geração procedural.

* Baseado na creepypasta "Backrooms".

* Espaços liminais.

* O jogo é dividido em 5 níveis, numerados de 0 até 4.

* Os primeiros quatro níveis contém, cada um, um item secreto, relacionado a uma missão secundária.

* O último nível é completamente seguro, a linha de chegada do jogo e o lugar em que o jogador completa a missão secundária, se e somente se tiver pego todos os itens secretos.

* Cada nível é lar para uma entidade específica, a do último sendo pacífica e as dos primeiros apresentando força progressiva.

* Para recuperar vida e para interagir com inimigos, o jogador coleta itens encontrados pelo mapa.

* Itens em todos os níveis, encontrados no chão, geralmente de uso único.

## Personagens

* Player (humano normal, controlado pelo jogador, múltiplos sprites para escolher um antes de começar cada corrida)

* Dollface (inimigo mili encontrado no nível 0, percegue o jogador perpetuamente, lento (em ataque e movimentação), dá pouco dano, pouca vida)

* Skinstealler (inimigo mili encontrado no nível 1, parece mas não é um jogador, percegue o jogador perpetuamente, velocidade média (em ataque e movimentação), dá dano médio, vida média)

* Hound (inimigo mili encontrado no nível 3, percegue o jogador perpetuamente, rápido (em ataque e movimentação), dá muito dano, muita vida)

* Still-life (inimigo mili encontrado em todos os níveis, pouca vida, dá pouco dano, se mexe apenas quando o jogador não está virado para ela)

* Faceling (n.p.c. encontrado no nível 4)

* Smiller (inimigo mili encontrado em zonas escuras, não sai do escuro (segue o player até a borda das trevas), rápido, pouco dano, (único) danificado por lanterna)

## Cenários

* Nível 0 (papel de parede amarelo, carpete cinza úmido, zumbido de lâmpada, claro)

* Nível 1 (armazém, chão de concreto com algumas poças de água e goteiras, paredes de concreto, ambiente cinza, algumas salas escuras)

* Nível 2 (túneis estreitos e retos de manutenção com canos metálicos no teto, algumas salas de máquinas, majoritariamente escuro)

* Nível 3 (fábrica, paredes de tijolo, chão de cimento, salas grandes, finito, fixo, sem geração procedural, claro)

* Nível 4 (tem um lugarzinho para fazer café com uma pia e uma tomada (o jogador pode ganhar o jogo lá, mas precisa ter todos os itens secretos), escritório abandonado mas conservado, carpete azulado, janelas brilhantes (sem ambiente fora), claro, fixo, sem geração procedural, uma cadeira em que o jogador consegue ganhar o jogo sem usar os itens secretos, uma mesa cheia de royal rashon)

## Itens normais

* Almond Water (cura pouco)

* Firesalt (arma, ilumina o lugar (temporariamente), insendeia os inimigos (d.p.s.))

* Carne (drop inimigo (cura muito))

* Lanterna (ilumina áreas escuras em formato de cone àfrente do jogador, renovada sempre que uma bateria é usada)

* Bateria (restaura lanterna)

* Royal rashon (catastroficamente raro, sempre maximiza a vida)

## Itens secretos (únicos para cada nível)

* Filtro de pano (encontrado no nível 0)

* Pó de café (encontrado no nível 1)

* Chaleira (encontrado no nível 2)

* Máquina cafeteira (encontrado no nível 3)
